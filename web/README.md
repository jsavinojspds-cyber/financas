# Comprovantes para iPhone

Versão web instalável pela Tela de Início, publicada junto ao projeto Finanças em `/financas/comprovantes/`.

## No iPhone

Abra o endereço no Safari. Toque em Compartilhar → Adicionar à Tela de Início. Fotografe ou importe uma imagem, confira data, valor, estabelecimento e cidade/UF. Escreva ou dite uma observação sobre a despesa. Na lista, os comprovantes aparecem por mês. Use **Compartilhar JPG** para enviar a imagem ao WhatsApp, Mail ou Arquivos; a cópia compartilhada recebe um rodapé com todos os dados conferidos. Use **Baixar mês em ZIP** para guardar todos os JPGs daquele mês juntos.

## Dados e limites

As imagens e os dados ficam no armazenamento local do Safari, neste aparelho. Eles **não são enviados ao GitHub**. A leitura automática usa Tesseract.js executado no navegador; o código e o modelo de português são baixados da internet quando usados. Se a leitura falhar, preencha os campos manualmente.

O Safari não permite que uma página crie pastas diretamente no app Arquivos. O ZIP mensal é o modo de guardar a prestação de contas organizada fora do app. Cada JPG também pode ser compartilhado ou baixado separadamente, com data, estabelecimento e valor no nome. Exporte os arquivos que deseja guardar fora do navegador; apagar os dados do Safari ou o aplicativo da Tela de Início pode apagar os comprovantes locais. A função de ditado usa o reconhecimento de fala disponibilizado pelo Safari e pode pedir acesso ao microfone. Se ela não funcionar, use o microfone do teclado do iPhone.
