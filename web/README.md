# Comprovantes para iPhone

Versão web instalável pela Tela de Início, publicada junto ao projeto Finanças em `/financas/comprovantes/`.

## No iPhone

Abra o endereço no Safari. Toque em Compartilhar → Adicionar à Tela de Início. Fotografe ou importe uma imagem, confira a data e o valor sugeridos e salve. Na lista, use Compartilhar para enviar o JPG ao WhatsApp, Mail ou Arquivos.

## Dados e limites

As imagens e os dados ficam no armazenamento local do Safari, neste aparelho. Eles **não são enviados ao GitHub**. A leitura automática usa Tesseract.js executado no navegador; o código e o modelo de português são baixados da internet quando usados. Se a leitura falhar, preencha os campos manualmente.

O Safari não permite que uma página crie pastas diretamente no app Arquivos. Cada JPG é compartilhável ou baixável, e o nome inclui data, valor e identificador único. Exporte os arquivos que deseja guardar fora do navegador; apagar os dados do Safari ou o aplicativo da Tela de Início pode apagar os comprovantes locais.
